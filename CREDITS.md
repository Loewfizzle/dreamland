# Credits

## Game

**DREAMLAND HEIST**: design, code, pixel art and music created with Claude Code.

## Art

All sprites, backgrounds, UI and effects are **original procedural pixel art** generated in code at load time (`src/art/`). No external image assets are used yet.

## Music & sound

All music, sound effects and ambience are **original and synthesized in real time** with the Web Audio API (`src/audio/`): Karplus–Strong plucked guitar, analog-style pads, synth bass, drum synthesis, and a generated convolution reverb. No external audio files are used yet.
